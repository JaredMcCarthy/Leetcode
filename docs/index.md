**La colección más completa de soluciones a problemas de [LeetCode](https://leetcode.com) en español.**

Este repositorio contiene soluciones bien documentadas enfocadas en:

- **Código limpio y legible** - Fácil de entender para todos
- **Explicaciones en español** - Para la comunidad hispanohablante
- **Análisis de complejidad** - Big O explicado claramente
- **Soluciones en Python** - El lenguaje más usado en entrevistas
- **Open Source** - ¡Acepto contribuciones de la comunidad!

Usa la barra de búsqueda 🔍 en la parte superior para encontrar problemas por número o título.

## Explorar Problemas

Todos los problemas están organizados en el [repositorio de GitHub](https://github.com/JaredMcCarthy/Leetcode).

Puedes navegar por:

- **Por número:** Busca directamente el número del problema
- **Por dificultad:** Easy, Medium, Hard
- **Por tema:** Arrays, Strings, Trees, Dynamic Programming, etc.

---

## Objetivos del Proyecto

Este proyecto tiene como objetivo:

1. **Ayudar a la comunidad hispanohablante** con recursos de calidad para prepararse para entrevistas técnicas
2. **Fomentar el aprendizaje colaborativo** a través de contribuciones de la comunidad
3. **Mantener un estándar de calidad** con código limpio y bien documentado
4. **Crear la colección más grande** de soluciones LeetCode en español
